# Web LAB-2 - Semantik ve Erişilebilir Portföy

## Hakkında
Bu proje, Web Tasarımı ve Programlama dersi LAB-2 kapsamında, semantik HTML5 etiketleri ve erişilebilirlik (A11y) standartlarına uygun bir kişisel portföy iskeleti oluşturmak amacıyla geliştirilmiştir.

## Öğrenilen Kavramlar ve Teknolojiler
- Semantik HTML5 (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)
- Web Erişilebilirliği (A11y) ve "Skip to content" yapısı
- ARIA Etiketleri (`aria-label`, `role`, vb.)
- React & TypeScript & Vite
